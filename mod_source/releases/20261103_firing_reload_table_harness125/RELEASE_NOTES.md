3. Asked what "reload skill" means. Answer: it is a unit stat (0 to 100) that makes that unit reload

## 2. The change

- **`FOURTH.RELOAD_S`:** generated by `tools\gen_reload_table.py` from the game's own tables
  (`main_units` -> `land_units` -> missile weapon, or the engine's weapon for artillery ->
  `projectiles.base_reload_time`, then the reload-skill term).
  - It covers 564 ranged units, keyed by the name `type()` reports in battle. Flying units are
    included: the game's `land_units` table holds every battle unit.
  - The build regenerates the table and refuses to ship one that differs.
- **The round-125 window is deleted:** 1.25 x the last measured gap, with drops less than 1 s apart
  counted as one volley. The field log showed it flicker on every unit.
- **Per ranged unit, per poll (250 ms):**

| Line | When |
|---|---|
| `FIRING ON` | the first ammo drop of an episode (the first shot). It says how long the target had been in range before it, and the unit's reload |
| `CAST POINT` | first shot + 0.5 x reload, once per episode. Logged only; nothing is cast in this round |
| `FIRING OFF` | no drop for 1.25 x reload (10 s for a unit missing from the table) |
| `IN RANGE` / `OUT OF RANGE` | the unit's current target crosses its own live `missile_range()` (`unit_distance`, edge to edge) |
| `AMMO` | each drop; a rise logs `RESUPPLIED (not a shot)` |

- New named constants: `FOURTH.AMMO_OFF_FACTOR = 1.25`, `FOURTH.AMMO_CAST_FRACTION = 0.5`,
  `FOURTH.AMMO_WINDOW_DEFAULT_S = 10`.
- The game-data set gained `land_units`, `missile_weapons`, `projectiles`, `battlefield_engines`,
  `missile_weapons_to_projectiles` and `main_units` (in `gamedata\wh3\`, regenerated by
  `tools\extract_gamedata.py`).

## 5. What the next battle answers

Play one battle with ranged units, then look for these lines:

- **`FIRING ON ... in range X s before it`**: how much warning the in-range moment gives before the
  first shot. A steady few seconds would let a cast land before the first shot; zero or "never"
  would not.
- **`CAST POINT`**: when, after each first shot, an ability would have been cast.
- **`FIRING OFF`**: whether each unit is now one steady episode.
